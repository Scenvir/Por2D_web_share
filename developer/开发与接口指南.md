# 开发与接口指南

本目录供 agent、自动化验证和物理行为分析使用。玩家启动及操作见包根目录的 START-HERE.txt 和 README.md。

## 文件与运行方式

- [完整接口与回放规范](SCRIPT_INTERFACE.md)：目录关卡、逐帧输入、状态读取、快照和版本 3 回放格式。
- [可运行示例](agent_example.cjs)：直接调用包内 WASM，无需启动浏览器或服务。
- 游戏核心与网页位于 `../runtime/dist/`；包内不包含 C++ 源码、求解器或编译工具。

安装 Node.js 22+ 后，在分享包根目录执行：

```powershell
node developer/agent_example.cjs
node developer/agent_example.cjs "回放文件.txt"
```

默认示例展示接口操作，不保证通关。指定回放时退出码 0 表示实际通关，2 表示输入耗尽但未通关，1 表示错误。

## 浏览器自动化验收

在包根目录启动 `node runtime/server.cjs --host 127.0.0.1 --port 8000`，将其作为后台进程管理，等待页面“开始游戏”按钮可用。结束后停止自己启动的服务。

阅读教程，实际通过第一章 Level 0；检查编辑器、回放导入和双客户端创建／加入房间。播放结束、截图或部分移动不能作为通关证明。浏览器自动化工具由调用方环境提供。

优先按按钮名称定位；画布坐标须按实际边界缩放，逻辑画布为 1000×600。联机验证使用独立浏览器上下文。存档按浏览器及访问地址隔离，回放和地图须主动导出。

包根目录的 SHA256.json 用于核对所有其他文件的一致性，不证明发布者身份。runtime/node_modules/ws/LICENSE 随依赖保留。
