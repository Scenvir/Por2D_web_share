Por2D Web · 如何双人联机

首次使用请先阅读 START-HERE.txt，游玩操作见 README.md。

一、准备
1. 完整解压 ZIP，不能直接在压缩包内启动，也不要直接双击 runtime/dist/index.html。
2. 仅作为主机的一台电脑需要安装 Node.js 22 或更新版本（推荐官网 LTS）：
   https://nodejs.org/en/download
3. 游戏和 ws 联机依赖已经打包，不需要 npm install、Python、编译器或 Emscripten。
4. 队友只需要浏览器，不必下载分享包或安装 Node.js。

二、同一局域网 / 同一 Wi-Fi 双人联机
1. 房主双击 start-lan.cmd，保持打开的终端窗口。
2. 房主在浏览器打开 http://127.0.0.1:8000。
3. 队友打开终端显示的房主局域网地址，例如 http://192.168.1.20:8000。
   队友不能使用 127.0.0.1 或 localhost，它们指向队友自己的设备；也不能用服务监听地址 0.0.0.0。
4. 房主在菜单点击“多人联机 · 创建 / 加入房间”→“创建房间”，把房间码发给队友。房间码可留空随机生成，也可自定义为 1–16 位字母、数字、横线或下划线。
5. 队友进入同一菜单，输入房间码并点击“加入房间”。房主选图即可开始，不必等第二人。
   房间最多 8 人，地图有 1 或 2 个操作席，其余玩家观战。观战玩家可在联机菜单接手空闲角色，
   操作玩家可随时转为观战；已在观战席的玩家不会自动接手角色。Ctrl 可切换到空闲角色。
6. 游玩期间保持终端窗口打开，结束后按 Ctrl+C 或关闭窗口。游戏内可点“离开房间”退出房间。

三、操作与规则

操作
第一、二章默认 A/D 按屏幕方向移动，W 跳跃，E 交互 / 进入出口，C 保存检查点，R 恢复检查点（未保存则重开）。
第三章中 W/A/S/D 对应屏幕上/左/下/右：逆重力方向为跳跃，垂直重力方向为移动，顺重力方向无效。
按住 E 会持续检测重力机关和出口，可以先按住再靠近；满足出口条件时优先进入出口。详见游戏内完整教程第 3 节。
鼠标左键放蓝门，右键放橙门；Z/X 也可向鼠标位置放门。
手机用屏幕按钮移动和跳跃，选择门颜色后在画面上拖动瞄准、松手放门（尚未在真机上验收）。
单角色为黄色；双角色场景（单机或联机）中 P1 为绿色、P2 为紫色，对方鼠标显示为带编号的十字光标。
双方共用一对蓝/橙传送门。角色互相碰撞，可以站在队友身上起跳。

过关与检查点
角色抵达出口、头部朝向一致并按 E 后消失，不再参与碰撞。
所有角色都过关后，主线进入下一关；主线末关、小节或自定义地图则就此结束。任一操作角色重试或碰到地图边界，会恢复共同检查点，未保存则重开本关。
保存检查点要求所有角色在门外连续静止 25 个逻辑帧；检查点只在当前会话有效，选关、过关或刷新后失效。

联机状态与设置
打开菜单、失焦或切换标签页只清除自己的输入，不暂停联机。（单人时打开菜单会暂停，失焦不会。）
任一玩家可在菜单→设置修改运行速度，双方同步。
双方的蓝/橙射线互相可见；瞄准预览只显示自己的，按 Q 开关。
房主可选关或切换自定义地图；联机可录制，教程和回放需先离开房间。

离开与接任
队友离开后房间和现场保留，空闲角色可由他人接手；房主离开后由剩余成员接任。断线后可重新加入仍存在且开放的房间；服务停止则现场丢失。

四、同一台电脑测试
双击 start-local.cmd，使用两个浏览器窗口（也可普通窗口加无痕窗口）访问
http://127.0.0.1:8000，然后分别创建、加入同一房间。
两人共用一套键鼠不方便同时操作，实际游玩推荐两台设备。

五、常见问题
队友打不开网页：确认双方连同一局域网；允许 Node.js 通过 Windows 防火墙的专用网络。
某些访客 Wi-Fi 开启了设备隔离，请换到允许设备互访的网络。
有多个地址：选择当前 Wi-Fi 或网线网卡的 IPv4 地址；可运行 ipconfig 查询。
端口被占用：使用已有服务，或在此目录终端执行
  node runtime/server.cjs --host 0.0.0.0 --port 8001
此时双方的网址端口也改为 8001。
出现 node 不存在：安装 Node.js 后重新打开启动脚本。

六、跨网络 / 公网
房间码只在同一个正在运行的服务器内有效，不会自动跨网络连接。
本分享包提供本机/局域网服务；不同网络的玩家需要部署可共同访问的 Node.js 服务
或配置双方可互访的虚拟局域网。本分享包不提供已托管的公网服务。
单纯上传到 GitHub Pages 等静态网站不能运行双人房间服务。

七、macOS / Linux
安装 Node.js，解压后在此目录运行：
  node runtime/server.cjs --host 0.0.0.0 --port 8000
再按第二节操作。Windows 启动脚本不适用于这些系统。

目录说明
runtime/dist/            已编译的游戏网页和 WebAssembly
runtime/server.cjs       房间服务，同时提供网页
runtime/node_modules/ws/ 已打包的 WebSocket 依赖（附 LICENSE）
start-lan.cmd    Windows 局域网启动入口
start-local.cmd  Windows 本机启动入口
